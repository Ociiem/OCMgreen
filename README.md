# OCMgreen

If you want your Blender to look like mine does in the videos, install OCMgreen.

There are two copies. Use the one that matches your Blender.

- Blender 5.1: `Blender-5.1/OCMgreen.xml` (this is the current look)
- Blender 4.2: `Blender-4.2/OCMgreen.xml`

## Install

1. Download the XML for your Blender version.
2. Copy it into the theme folder for that version. On Windows that is:

   `%APPDATA%\Blender Foundation\Blender\5.1\scripts\presets\interface_theme`

   Use `4.2` in that path if you are on Blender 4.2. Create the `interface_theme` folder if it is not there.
3. Restart Blender.
4. Open **Edit > Preferences > Themes** and choose **OCMgreen**.
